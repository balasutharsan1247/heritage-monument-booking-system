# Government Data Intake

This directory is intended for preparing and validating government visitor data before it is used for ML model training.

## Important Rules

1. **Confidentiality:** Do not commit raw government data, exports, local reports, or credentials to Git.
2. **Data Placement:** Authorized data files (CSV or JSON) should be placed locally in the `raw/` subdirectory (e.g., `backend/data_intake/raw/data.csv`).
3. **No PII:** Ensure all data is anonymized and contains absolutely no Personally Identifiable Information before placing it in the `raw/` directory.

## Directory Structure (Local Only)
- `raw/`: Place your authorized, raw `.csv` or `.json` files here.
- `exports/`: Use this for any intermediate processed data.
- `reports/`: Local validation reports generated by the validation script.
- `credentials/`: Any API keys or credentials needed for data access.

These directories are ignored by Git via the `.gitignore` rules.
